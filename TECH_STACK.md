# Tech Stack & Implementation Details

This portfolio is built using a modern, performance-first frontend architecture designed to showcase data engineering and analytics expertise with a premium "Galactic" aesthetic.

## 🛠️ Core Technologies

### **Frontend Architecture**
*   **HTML5**: Pure semantic markup for optimized SEO, accessibility, and clean document structure.
*   **CSS3 (Modern Design System)**:
    *   **Design Tokens**: Implemented a comprehensive CSS Variable system for global theme management (colors, spacing, typography).
    *   **Glassmorphism**: High-end UI effects utilizing `backdrop-filter`, selective transparency, and multi-layered shadows.
    *   **Layout Systems**: Advanced layouts using **CSS Grid** for the project gallery and **Flexbox** for individual component alignment.
    *   **Responsive Design**: Mobile-first approach with fluid typography and adaptive grid systems.
*   **JavaScript (ES6+)**:
    *   **Feature-Based Architecture**: Modular initialization of standalone features (starfield, typing effects, scroll detection).
    *   **Performance Optimization**: Utilizes lightweight, vanilla implementations to ensure fast load times and smooth 60fps animations.

## 🌌 Key Technical Features

### **Dynamic Visual Systems**
*   **Starfield Engine**: Custom particle system built with the **HTML5 Canvas API**, featuring procedural generation of stars and parallax depth.
*   **Intersection Observer API**: Highly efficient scroll-driven animations and section fade-ins.
*   **Typography Engine**: Dynamic typing effect with custom timing logic for engaging user introductions.

### **UI/UX Engineering**
*   **Custom Design Tokens**: A single-source-of-truth style system that allows for instant theme modifications.
*   **Tilt & Hover Interactivity**: 3D transform animations and border-glow effects for enhanced interactivity on project cards.
*   **Modern Accessibility**: Aria-labels, semantic hierarchy, and descriptive metadata for all interactive elements.
